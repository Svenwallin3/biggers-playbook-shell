# Biggers Platform Shell

Create a new internal web app called "Biggers Training Platform" for Biggers Market. This is Stage 1 of a staged, multi-session build, keep this first step minimal on purpose: just scaffold a blank app shell using the default stack (React + Tailwind + shadcn/ui) with a simple top-level layout/navigation placeholder and a blank home page. Do not build out individual screens yet, do not add Supabase or any backend yet, do not add real content yet, those come in later stages. I'll add full project context via the project Knowledge panel immediately after this.
