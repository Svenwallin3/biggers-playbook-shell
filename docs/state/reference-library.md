# Reference Guides

## Live

- `/reference` with tabs: Sourcing, Checklists, SOPs, Portioning & Presentation, Manager Guides.
- **Checklists and SOPs** group by Division (Company-Wide, Kitchen, Markets, Delivery), collapsible, with type filter chips and a "My location only / Show all locations" toggle. Print works on every Reference screen.
- **Digital checklists:** one shared instance per document, per day, per Location, with line-level completion and a submit gate. Scoped by Division and Location in RLS (ADL-094).
- **Sections** inside a document are each either a checklist or a paragraph (`content_kind`), can be converted and drag-reordered by Owner/GM.
- **Manager Guides:** grouped by Division with an inline Location tag; checkboxes are local only (no daily record, no submit). Includes the day-based Kitchen guides, Day 1 Market guide and "How to Run a Walkthrough (Kitchen)".
- **Editing:** pencil icon everywhere. Owner and GM (own Division) edit directly; regular Managers suggest. Document title, group, Divisions and Location are editable. Owner-only create and delete; GM can request a delete.
- **Sourcing Board:** full create/edit with photo upload; deletes need GM or Owner approval.
- **Portioning & Presentation:** table exists, no entries yet.
